# SlugcatPet Extended

Windows 桌面宠物：让 Rain World 的蛞蝓猫住在你的屏幕上。

fork 自 [lingxiaojun/slugcatpet](https://github.com/lingxiaojun/slugcatpet)。在原版基础上修复了脸部表情问题，并加入蜥蜴、面条蝇、蝉乌贼、拾荒者、珍珠、矛、爆米花、业力花等可放置生物与物件；AI、交互、物理、渲染都对齐原版（反编译 + wiki 双来源）。

## 运行要求

- Windows 10 / 11
- 从源码运行需要 Python 3.10+
- 首次初始化需要本机已安装 Rain World（含 Downpour / More Slugcats DLC）

## 安装与运行

```powershell
pip install PySide6 UnityPy numpy Pillow
python run_slugcatpet.py
```

首次启动会引导你选择本机的 Rain World 安装目录，从中一次性提取精灵图集到 `~/.slugcatpet/assets`，只存放在你本机、只供本程序使用。

release 压缩包里的 `SlugcatPet.exe` 可直接运行，不需要 Python，也不需要游戏。

## 玩法

### 放置

侧边工具栏可以往屏幕上放东西，**所有物件都没有数量上限**：

竖杆 / 横杆 / 果子 / 石头 / 灯笼 / 黏菌 / 蝙蝠 / 蜥蜴 / 蝉乌贼 / 面条蝇 / 拾荒者 / 珍珠 / 矛 / 爆米花 / 业力花。

- 点图标 → 鼠标变十字 → 在屏幕上点一下放下；Esc 或右键取消。
- 设置面板里有「自然生成」勾选表，列出全部可放置种类，勾中的会自己出现在窗口里（不限数量）；以后新增种类会自动出现在表里。生成的高度按种类随机：果子挂在半空（15%~75% 高度），蝙蝠 / 蝉乌贼 / 面条蝇飞在中层空域，石头 / 矛 / 珍珠 / 灯笼 / 黏菌贴着地面一段范围，爆米花与业力花只长在地面上。
- 鼠标按住任何物件都能拖着走，松手放开；可以丢、可以扔进水里、可以把尸体甩出窗口外（非蛞蝓猫的尸体出屏即清除）。
- 蛞蝓猫拖到屏幕边丢掉的尸体一定会在过边时被清掉（只有它亲手拖过、丢出去的那具；别的尸体照常按出屏半径判定），不会卡在屏幕边缘。
- 鼠标甩着矛松手＝正常投掷（矛头朝前、能伤人），不是翻滚版。
- 工具栏最后两个按钮：**橡皮**（点谁删谁，蛞蝓猫除外）与**清空**。
- 托盘右键菜单的「允许劫持光标」可以关：关掉后蛞蝓猫不再抓走 / 抢走 / 击落系统光标（只是指着光标、盯着光标之类照常），被抱住的鼠标也不再被当成杆。

### 蛞蝓猫

欲望分六类：进食、恐惧、战斗、玩耍、睡眠、社交。

- **进食** —— 手上的食物要一口一口吃完，果子 / 面条蝇 / 蝉乌贼 / 爆米花都有逐口变化的外观；吃饱后会去帮没吃饱的同伴找食物。咀嚼分成「抓取 / 咀嚼 / 咬合点 / 消失」四段：只有播放到咬合点那一帧才真的少一口，只有口数真的归零才消失；中途被打断只停动画、不额外扣口数（半吃的食物保持被吃过的外观），重新拿起一定重走完整前摇。普通重力与零重力叼嘴共用同一份咀嚼周期。
- **面敌（恐惧 + 战斗合并）** —— 约 1/3 桌面宽内有活威胁时优先级最高：睡着的会被叫醒，圈里还有威胁就睡不着。进威胁圈只有一个统一入口做决策：手上有矛 / 石头就在合适距离回身投掷；空手会走去捡矛或石头（走到手够得到的位置为止，不会站在矛边发呆）；捡不到、又被逼到角落才撤。撤退方向永远是远离敌人（不会朝敌人走），也不为了一具尸体往敌人身上贴 —— 善良的猫只救不在刀口上的同伴。退无可退时不再往墙角里挤 —— 被一路逼退够远 / 够久，或者背后是墙又一段时间没挪动，就当场转身面向威胁、从它头上跳到对面去接着逃（只要它还在一跳可及的范围内；跳完重新记账，不会在空中又判一次）。勇敢的猫会拔下敌人身上的矛再投回去。空中不做决策，落地重新评估。圣徒在业力与饱食都满时主动超度威胁。匍匐只在真的绕到蜥蜴背后时才会出现，能降低被它选为目标的概率。
- **战斗** —— 会投矛、扔石头、反击；勇敢的猫会拔下蜥蜴身上的矛再投回去。投掷前先看视线，中间挡着同伴就不扔；被逼到退无可退会面向威胁跳过去。目标比自己高就先起跳，跳到同一层再把矛掷出去（不会站在原地反复跳却不投）。迎战、掩护、逃跑一旦定下就是锁：取食欲望不会把它拆走。空手绝不主动扑向敌人 —— 没武器就先去找武器。
- **玩耍** —— 吃饱后捕食变成娱乐：追蝙蝠、追蝉乌贼（抓住但不杀）、把玩矛和石头、边走边跳；暴躁的猫会把矛和石头丢出去。性格不同，玩的东西也不同。
- **各挑各的目标** —— 同一堆食物/猎物/玩具前，每只猫各有稳定的个体偏好（同一只猫对同一件东西的偏好永远一样，换次启动也一样）；目标被同伴认领会自动让位，旁边围着的猫越多「拥挤成本」越高，刚试过拿不到的目标短期进黑名单；每只猫的决策相位还彼此错开，不会十只猫同一个心跳一起扑同一个最近目标；一件东西同时只站得下几只猫（果子两侧 2 只、围蜥蜴 3 只、救援位 1 只……），排不上的人在等待名单里 —— 排队不是禁止，这件东西照样可选，只是在打分里更贵。位形槽不只是数字：它决定这只猫**站哪一格**（第一只直奔中心，第二只站左边，第三只站右边），所以两只猫能同时吃一颗果子而不会挤在同一格上；站位点每帧跟着目标走，被挡住就退回直奔中心。
- **事件总线** —— 「发生了什么」和「谁怎么反应」是两件事：动作只往窗口的事件总线上记一条事实（谁、对谁、多重、哪一 tick），附近的生物各自解释。日志按窗口存，读的人用事件序号取「我还没看过的」，所以同一 tick 里先后发生的事一条都不会漏；出了目击半径就当没看见 —— 屏幕另一头发生什么不会改变我对某只猫的看法。
- **动态关系与记忆衰减** —— 每只生物对每个打交道过的对象有一份实时关系：物种基线 + 长期好感 + 短期情绪 + 恐惧 / 记恨 / 亲近 / 敬意 / 支配度。事件写账，每 tick 往基线衰减：短期情绪几秒散掉，记恨约一分钟淡光，长期没有互动的旧关系直接清掉。不会永久记仇，也不会因为一件事影响一辈子。
- **社会反应选型** —— 同一条事件有九种反应（算了 / 指向 / 指指点点 / 跟上去 / 换目标 / 挑战 / 请求 / 交易 / 围观），分数由「事件基础分 + 性格九轴 + 我对它的关系 + 当下情境（手里忙不忙、有没有威胁、远不远）」合成，再按个体随机抖动选一个。所以同一件事，暴脾气的猫会去指责，好脾气的猫觉得无所谓；被同一个人抢过两次，第二次明显更容易吵起来。反应可能什么都不做 —— 那不是没实现，而是这只猫对这件事的解释。
- **被抢了要讨说法** —— 目标被别的猫拿走时只认真正拿走的那只（认不出是谁就不冤枉最近的同伴），并记一笔账：这人之后靠近时社交动作明显偏向指指点点；旁边的同伴看见了有概率跟着一起起哄。抢位形槽抢输也算：排不上的人先看那个占到位的家伙一眼，按脾气与「爱指指点点」的程度决定要不要记下这笔账、等腾出手来去指指点点（太远、手里正忙、正做着别的社交动作就作罢 —— 社交动作一律不强制）。
- **睡眠** —— 睡前要磨蹭很久（睡意从 0 缓慢涨到 100），睡着后 20~40 秒随机自然醒；入睡立刻结算睡眠饱食度并加一级业力。同伴都睡着时，社交欲望攒满会去摇醒它们。睡眠意图只活在休息态：一旦被涉水 / 无重力 / 冷水 / 爆炸 / 被抓等任何原因带离趴睡态，蜷缩姿态与睡意当场撤掉（起床动画例外，靠渐退），不会出现闭着眼耷拉着头还在活动的半睡姿态。
- **社交** —— 见下表。
- **个体性格** —— 每只猫的性格＝种族原型 + 一份固定的个体偏移（由出生序推出，同一只猫永远同一份、重启也一样）：好动 / 社交 / 脾气 / 勇敢 / 善良 / 耐心 / 冒险 / 匍匐 / 指指点点 / 赶时间 / 摇醒 / 嬉水各有各的偏差，偏移幅度收在 ±0.5 内，所以不会出现「猎手胆小得像黄猫」这种串味，但同一族里也看得出个体差别。
- **手与槽位** —— 右手（主手）、左手（副手）、背部（猎手系专用，只放矛）、胃（预留）。先用右手；右手被占就用左手；双手都有东西时优先用右手，要腾手就先放下右手的。一只手也能爬杆、吃东西、跳跃，物品跟着手走。把矛收到背上时手会先松开，同一根矛不会同时占着手和背；从背上抽矛回来不需要重新等手上的冷却。
- **上手冷却** —— 拿到非食物后压 0~3 秒随机冷却才会用；拿到食物按饱食度放大上限（每格 +1.5 秒）。
- **清场** —— 场上有不能吃的尸体（死蜥蜴等）时会走过去拖到最近的屏幕边甩出去，出屏即清除；只在闲下来时做，有活威胁时先躲，一具尸体同时只有一只猫去拖。拖拽速度按被拖对象的体重算（原版绳约束的质量比 `num6 = 被抓节质量 / (猫胸节质量 + 被抓节质量)`，被拖物总质量轻于猫时再减半）：绿蜥只有平时的 12%、粉 / 白蜥 33%、蓝蜥 43%、拾荒者 41%、蝉乌贼 68~72%、蝙蝠 93%，拖着越重走得越慢。
- **鼠标互动** —— 抓着它走；手上有东西时剧烈摇晃会让它丢下手里的东西。右键猫身（或点状态栏里那只猫）可以「杀死该猫 / 操控该猫 / 打开设置」，杀死不弹确认。
- **状态面板** —— 名字旁实时显示这只猫此刻在做什么（正在指指点点 / 正在围观 / 正在追飞虫 / 正在找矛 / 正在准备猎杀 / 正在救人……），标题栏右侧的 ✕ 可以直接关掉面板。
- **表情优先级** —— 视线与表情按优先级合成：社交动作的起势、抢输时看那一眼走「紧急」档，压得住走路途中随手写的那句；睡姿与尸体的「不许挂清醒表情」走「强制」档，谁也顶不掉，收势必须和起势同一档才收得掉；每帧清一次，上一帧的优先级不会漏到下一帧。
- **伤害与复活** —— 被咬或被矛击中按攻击者的数据结算昏迷或死亡；昏迷过一会儿自己醒，死亡要同伴用双手按压才会复活，死亡掉一级业力。按压时施救者身体和两只手一起往下使劲（手会按进目标身体里一点），并借「晕眩」那张脸演憋着一股劲儿的样子（只借表情，不是真晕）；按完的对象复活。
- **救同伴** —— 「倒地的同伴」＝真死或被打晕，两档都算（晕过去的按不活，过去拍拍）；一只倒地同伴同时只归一只猫救（认领制：施救者自己倒下、放弃、或救活了才重新开放）。赶路复用觅食那套表面寻路：同层直接走过去，同伴在平台上 / 杆上 / 隔着缺口时改走「走 / 跳 / 落 / 爬杆 / 上窗口顶边」，不再只朝它的横坐标干走。到位口径与双手几何统一 —— 两只手真按上才算到了。被威胁打断只是短冷却（约 2 秒）马上能再上手，只有磨到超时才进长冷却。没有威胁时也看善良度：善良度高的必去，其余按善良度掷骰。
- **集体转生** —— 场上所有猫都死透之后守灵一段再一起转生；守灵与倒计时期间不冒任何灵光粒子，世界照旧、尸身还在，同伴仍可最后扒拉救回。全体复活的那一瞬，每只猫在落点炸开一圈 18 点白点＋一圈冲击环。全体复活的那一瞬清空场上所有东西（物件、生物、尸体、还没长出来的业力花排期一起清）：新雨循环＝整个房间重置，不会留下上一轮的残局。

### 地形

- **窗口边缘就是墙和地** —— 工作区左右边缘是墙，上边缘是地面；别的窗口顶边是一块单向平台，从上方落下会站上去，窗口本体不挡路（`window_platforms=false` 可关）。被前面窗口盖住的顶边不算地面；最大化 / 顶边贴屏幕顶的窗口自己不是平台，但它照样遮住后面的顶边（不会留下一块踩得上去的隐形平地）。
- **隐形窗口不算平台** —— 挂起的 UWP（DWM cloaked）、全透明的分层窗、工具窗 / 不激活 / 点击穿透 / 无表面宿主，以及输入法、讲述人这类窗口类：看着占一个大矩形、屏幕上却一个像素都没有，一律不进平台表（否则猫会悬在空气里「走」）。
- **屏幕顶边不能攀附** —— 只有圣徒的舌头能粘住顶边悬挂，其他猫到了顶边只能站着或者掉下来。
- **墙不可攀爬** —— 只有「贴墙下滑」和「下滑中按跳跃＝蹬墙跳」两种行为；想升高只能靠真竖杆。
- **路线按性格挑** —— 每条路拆成耗时 / 体力 / 风险 / 噪音 / 精度 / 后摇六个轴，再按性格折成一个排序代价：谨慎的猫宁可绕路（跳跃只快 10% 也不跳），敢冒险、赶时间的猫才愿意赌跳跃（风险轴只跟风险偏好走，不与战斗用的勇敢度重复计）；好动的猫不在乎多花力气，急性子最讨厌落地要重新站稳。风险按耗时比例折算（省的时间值不值得赌，取决于这段路有多长）。耗时的真实值不被改动，执行器的超时与进度判断照旧。
- **落点安全边距** —— 可接受的落点不是整块平台，而是内缩一圈的那一段（平台宽 100 只认 12~88；平台太窄就按中线判）：「理论上跳得过去」和「AI 愿意跳」是两回事。
- **杆子** —— 横杆与竖杆都能爬、能站、能跳；杆上能摘果子、投矛、抓飞虫、捡东西；能带方向与距离跳到另一根杆并在空中抓住；交叉口经过时有概率切换横竖；杆头只站一只猫，被挤时按性格分流（让开 / 等 / 硬挤）。杆上没有匍匐也没有睡姿 —— 在杆上就站着走完，不趴下也不入睡。走横杆按地面移动的口径扣体力，不额外算攀爬。
- **光标＝一小节悬空短杆** —— 鼠标是一根长度等于光标本身大小、底部不接地的短竖杆，猫会当杆爬，甩鼠标能把猫甩下来。猫的脚不在杆的竖直跨度内就够不着，鼠标抬高时地面的猫不会顺着它凭空爬上顶端。抓着猫、拽着东西、正在放东西时，以及松开鼠标后的 2 秒内，这根杆不出现。
- **扎进墙或地面的矛＝杆** —— 近垂直扎入的矛会变成对应长度的杆，谁都能爬；猫拔不动，鼠标一拽就能连矛带杆整根拔下来（工匠也拔得动）。
- **被挡路** —— 平地先跳，跳不过才指指点点（暴脾气的猫会上来就指）；在杆上被挤也按性格让路。
- **移动数值** —— 跳跃初速 8/7、按住续力、蹬墙跳 8/7 + 6/5、跑步 4.2、匍匐 4 全部照 `Player.cs`；站立跳约 44px、跑跳约 83px。
- **跳跃带方向与距离** —— 每一跳都由高度 / 距离档与左右方向两个参数决定；杆上跳出分「beam jump」与「离杆平跳」两档。
- **跳也是寻路的一步** —— 走不到、也够不着的窗口顶边，会挑一条「跳 / 跳落 / 后空翻」的实测轨迹落到那块面上，落地后再走完最后一段；跳不上去的顶边不硬跳。
- **两段路线** —— 果子挂得比自己站的地方高、直接够不到，但站上旁边那块窗口顶边就够得到时，会先跳上顶边再伸手／起跳去摘（地板→顶边→目标）。找不到这种中转路线才放弃。
- **落地要落对地方** —— 「跳起来摸到目标」（抓飞虫 / 摘果 / 攻击 / 舌钩补救）和「以位移为目的的跳」分开判定：后者必须落在有效支撑面上、且落点离目标不超过一个身位，摸到又弹回原地不算走通。
- **后空翻** —— 所有猫都会：约 55px 高、175px 远，是跳弧够不到时的最后手段；普通跳就够得着的目标，只有天生爱翻的个体（溪流那种高机动／高冒险／好动）才会一时兴起翻一个，同一只猫对同一个目标的选择永远一致。

### 位移动作

照 `Player.cs` 的 BellySlide / Roll / Flip / RocketJump 分支实现，操控模式下可直接用：

- **滑行** —— 奔跑中「下＋跳」滑铲：起始后蹬一下，之后按 `sin(rollCounter / 15 · π)` 逐帧推进（溪流无后蹬、峰值 25、周期相同）。
- **滑扑** —— 滑行中按跳＝滑铲火箭跳（`RocketJump` + `rocketJumpFromBellySlide`），滑得越远弹得越远；落地转翻滚。
- **滑翻** —— 滑行中「后退＋跳」＝甩鞭后空翻（`Flip` + `whiplashJump`），能整段越过蜥蜴。
- **蓄力前扑** —— 趴下按住跳逐帧蓄力（上限 20 帧），松手按蓄力档放前扑 / 超级跳。
- **抛物增距** —— 掷物给躯干反冲（躯干 +8、髋 −4，净 +4 前冲，爬杆时是 2 / 8），空中或跳跃开头掷出能把跳跃 / 前扑明显拉远；滑行的第 8~15 帧同向掷物再给物品额外 +15 动能（矛必定插墙并额外下压 5）。
- **长滑铲** —— 滑行中反向掷物：`rollCounter` 归 8、身体后坐，转进 39 帧周期的长滑铲（峰值 14），收尾站起再弹一下。
- **后空翻时下 / 上掷** —— 后空翻中只按上 / 下键，矛沿竖直方向掷出：矛尖朝掷出方向、初速 ±40×frc、擦到侧壁不插墙，能钉地上。
- **轻抛角度档（圣徒投矛）** —— 按输入选档：平抛 60° / 斜上抛 25° / 纯上抛 5° / 后空翻下掷 180°（力度 12.5 / 9 / 8 / 8，朝向随掷出方向）。
- **拾取与投掷** —— 控制态有原版的拾取 / 投掷键：右手优先拿；手里有东西就先放下右手的，再抓最近的可抓物（矛与身前的东西更好抓）；投和拿都要等上手冷却（0~3 秒）。

### 决策与寻路

- **统一动作注册表** —— 每只猫「这一 tick 做什么」只有一个出处（`behavior/action.py`）：每个动作都登记成 `ActionSpec(key, band, pre, gate, start, tags, cooldown, interrupt)`。主 tick 按 band 顺序仲裁：`emergency`（溺 / 无重力 / 避水 / 趋暖）→ `need`（醒醒 / 让路 / 面敌 / 社交 / 进食 / 玩 / 睡）；band 内顺序即优先级，`pre` 无条件先跑（记账），`gate` 决定做不做，`start` 做事。性格层是唯一掷骰的 band（`mood:` 候选表按权重随机），由空闲态查询。角色独有动作（圣徒超度威胁 / 工匠爆跳夺物 / 溪流夺物）登记在同一张表的 `preempt` band，起手点留在各自 ticker 的原位。调试面板与测试可读 `actions.trace`（本 tick 真的做了什么）与 `actions.errors`（被挡下的异常）。
- **表面图寻路** —— `planning/surface.py` 把地板段 / 窗口顶边（单向平台）/ 竖杆顶 / 横杆面建成一张图：`Node` 是支撑面，`Edge` 带类型（walk / jump / drop / climb_pole / pole_beam / finish）、起终支撑面、是否落地、终点姿态、耗时、体力、风险；用 Dijkstra 出 Route，代价走六轴模型 × 性格。执行器按第一条边建既有控制器（`HopReach` / `PoleJumpReach`），落地后重新规划接下一段，于是「地板 → 低平台 → 高平台 → 目标」这类多段路也有人走了（旧的两段实现在这里只会放弃）。杆只有「抓住」不给「落上去」：能给出的边一定能被对应执行器跑完。

### 蜥蜴

- 品种按放置顺序轮换（粉 / 绿 / 蓝 / 黄 / 白 / 红 / 黑 / 蝾螈 / 青），个体颜色、尾色、背刺随机；绿 / 粉 / 白按原版外观还原，白蜥是随机淡彩色。
- 头部 5 张贴图按 `headDepthRotation` 实时选行（正侧面 / 斜侧面 / 斜正面 / 正对镜头）；转身时支起上半身，把头从一侧绕过身体转到另一侧，转完落回。
- 躯干与尾巴是原版 BodyChunk + BodyChunkConnection 的质点模拟；头部颜色在深色与个体色之间呼吸闪烁。被鼠标拎起来拖动时身体会明显被拉长，停下后收回设计长度。转身时锚点（头后方 `head_conn`）平滑滑过头顶、不再瞬移到头的另一侧：身体按转身进度滑过去，`depth` 一路扫过中间几行头片，转完落回；链节每 tick 的位移有上限，不会被解算器灌出炮弹速度。
- **动画吃到 AI 意图** —— AI 只产出「这一帧想要什么」（注视对象、警觉 / 攻击 / 恐惧、下颚开度、支起或压低身体、步态），动画层照着演：头片朝向 = AI 算出的注视角，目标在上就抬头、在下就低头，颈部跟着抬 / 压；转身、闲逛、扑咬各有不同的跟随速度。下颚是独立动画通道 —— 追猎只是盯着（不张嘴）、威吓半张、扑咬微张、咬住全张、叼着猎物半张、被拎着挣扎半张，不再是「一进追猎就一路咧着嘴」。
- 躯干不再每帧被强行摊平到水平线：顺直约束沿父节当前方向，转向时头先转、身子依次跟上、尾巴最后甩过来（弯曲惯性）；步态相位随走动推进（躯干起伏 + 尾梢摆动），每只蜥蜴还有自己的低频动画相位，个体之间不完全同步。
- AI 分四层：感知（同一份世界快照 + 视野锥 + 遮挡判定：杆子或别的生物挡在中间就看不见；威胁只看距离与遮挡，不看视野锥）→ 记忆（置信度：看见就涨，看不见按 0.975 衰减；高于 0.55 继续追，0.18~0.55 去最后看见的位置找，低于 0.12 才忘）→ 行为效用（逃跑 > 回巢 / 搬运 > 受伤 > 同族竞争 > 撕咬 > 争夺 > 狩猎 > 守猎物 > 查探响声 > 结伴 > 游荡，照 `LizardAI.DetermineBehavior`）→ 动作（走路 / 起跳 / 伏击 / 扑咬）。决策只产出行为名，不改速度和位置；整场蜥蜴每帧走「全体感知 → 各自决策 → 一起执行」三段，没有数组顺序上的先手。
- 接近规划：目标在同一层就直线扑；目标在头上就先在它两侧搜一个起跳点，用本体同一套重力与阻力模拟弧线，按品种偏好（绕路 / 落点误差 / 贴墙风险 / 接近角度 / 起跳倾向）打分选最优那条。白蜥与蝾螈是伏击型，猎物还远就原地等它靠近。
- 虚拟巢穴：屏幕左右两侧就是两个 VirtualDen。蜥蜴叼住猎物的那一刻按「哪边近」定下要回的巢穴，之后一路走到底，不会走到屏幕中间又换边；到了就放下，尸体在巢穴边守一会儿，昏迷的在巢穴里咬死。
- 猎物归属（`PreyTracker`）：只有被自己咬倒 / 咬死的猎物才算自己的，别人叼着的不抢，路过的蜥蜴只接手没人认领的那具；送回巢穴后归属结束。
- 同族社交（`SocialMemory`）：记支配度、认怂、敬意与怨气；已认怂的同族不再容易激怒自己（撕咬权重 ×0.35）；搬运路上被更强的同族盯上会举头警告并加速回巢，拦住去路的低支配个体自己让开。
- 黄蜥 Pack：共享的是「谁在哪看见了猎物」的情报而不是站位，同伴按自己的序号错开包夹位置（0 / +74 / −74 / +148），不挤同一个点。
- 石头能砸晕蜥蜴。它会叼走死掉或昏迷的蛞蝓猫回巢穴再咬死，优先级是「叼走 → 咬死昏迷的 → 打最近的活猫」。
- 不把鼠标当威胁：光标停在它身上也不会吓到它，照常狩猎、撕咬。
- 有仇的更想打：蜥蜴也读同一张关系表 —— 记恨过谁就更想咬谁，怕谁就更把它当威胁躲开；被人用石头或矛打伤、看见同伴被咬，附近的猫都会各自记一笔（怕它 / 恨它 / 敢不敢打），这份账随时间衰减。
- **驯服** —— 场上有没被驯服的蜥蜴时，蛞蝓猫会去抓落地的蝉乌贼送到蜥蜴嘴边（原版 `FriendTracker`：活礼 +0.6、死礼 +1.2，好感超过 0.5 即认主，从此只跟着猫走）。端着礼物的猫不会被咬。

### 其它生物与物件

- **蝉乌贼** —— 悬停飞行，被靠近就扑翅逃跑，会蓄力冲撞；体力回得快、几乎不用休息；被吃时有逐口变化的外观。蛞蝓猫能徒手抓住飞行中的蝉乌贼，抓住的乌贼会带着猫飞一点。
- **面条蝇** —— 幼体 80% / 成体 20%，体型与颜色每只都不同（照 wiki 调色板）。幼体 5 口可吃，被抓住 3 秒即死亡（圣徒拿着不死），惨叫把母亲永久惹成死敌；平时不愤怒，小幼体不攻击也不愤怒。成体会用獠牙戳（晕 + 掉东西）和突刺（致命），会闪避矛与石头，也会主动追猫；獠牙扎进墙或地面会把身体挂住 0.5~1 秒才拔得出来。被鼠标拖着走的手感与拖蛞蝓猫完全一致。圣徒的舌头能黏住任何活着的生物当玩耍（黏住期间一路扣体力、拉空自动松舌，全程不摆匍匐也不入睡），成体被黏会当场永久记恨，幼体被黏当场送命。被激怒的成体算威胁。
- **拾荒者** —— 外形严格照原版 `ScavengerGraphics` 拼装：髋 7 / 胸 9.5 / 头 5 三个体节（链长 18 与 22）、Circle20 的躯干与头、`Futile_White` 三角网格的腰与腹斑、`LizardScale` 背刺 / 绒簇（图案与尺寸按原版随机表）、`ScavengerHandA/B` 手掌、耳须与精英面具；图层顺序照 `AddToContainer`（后腿 → 后手 → 尾与背饰 → 胸/髋/腰/腹斑 → 前腿 → 前手 → 颈 → 须 → 头 → 齿 → 眼 → 面具），个体差异与配色照 `IndividualVariations`。看近处物时上身后仰、头随视线转，抬头与眼神都有过渡；头脸朝向按原版 `-DegToFloat2(-BodyAxis)`（不是随手翻转），转身时上半身支起、头绕身体连续摆到另一侧。
- **拾荒者的行为** —— 持矛巡走，背上另插一支备用矛；蜥蜴或猫靠近就站定举矛指向、掷矛，掷完逃跑；受伤到一定程度会从背上拔矛应战。每一只的性格都由攻击性 / 勇敢 / 支配度 / 精力 / 神经质 / 心软六项按 wiki 的分布随机生成，落到警戒半径、走路速度、瞄准时长、逃跑时长与接纳猫的门槛上（只是幅度不同）；支配度低的个体自己就会给高的让开位置。对蛞蝓猫的起始好感照 wiki 各角色的声望给定（圣徒/求生者中立、黄猫偏高、猎手/工匠偏低），之后只被「被打」与「给珍珠」改变，不会自行升降。只收珍珠：果子石头递到面前也不拿；收下珍珠后好感拉满、不再把猫当猎物，并回赠一支矛。
- **珍珠** —— 很弹，落地会蹦几下；溪流特别喜欢，会专程去叼着把玩。
- **蝙蝠** —— 偏爱低空飞行且停留更久；蛞蝓猫会抓它，也会用矛和石头打它。贴图是原版的 4 片精灵（FlyBody / FlyWing×2 / FlyEyes），图层序、扑翅角度、收窄与翅锚点全部照原版：翅根在身体两侧、翅尖朝上张开，不会上下颠倒。
- **爆米花** —— 从地面长出来，可任意高；只能用矛敲开，敲开后可以吃。
- **圣徒的超度** —— 优先选敌对目标。

### 业力花

- 只能长在窗口地面，花头高度固定；扎根后弯着从地里钻出来再支起。鼠标拖扎根的花是「软拖」（花头被拉开、根不动），拉开够远会「啵」一下连根拔起（茎有弹性反冲），之后就能像拖物品一样拖着走，也能丢掉。
- 4 片花瓣 + 6 节带物理的茎（拔起后茎也有重力）；花瓣被啃逐片消失，啃完 4 口整株消失；花环是四片花瓣连成的扁圆，模拟侧面视角。
- 吃花前必须先拔花：猫伸手摘、鼠标拖都是同一套弹性势能（花头先被拉开，拉开够远才「啵」一下连根拔起，茎随之反冲回弹），根还在地里时吃不到嘴里。
- 蛞蝓猫有一条隐藏的一格业力花条：吃花即满，满了就不再拔花；有花条时死亡不掉业力并消耗花条，没花条则掉一级。
- 拔花不走觅食：业力花不填饱食度，由独立的行动链去摘（有自己的一套冷却），所以它既不会顶掉真正的觅食欲望，吃饱了也不会反复去薅花。
- 花条满了以后业力花就从所有自主进食候选里彻底消失（专用链与普通取食链一起堵）：吃完一朵立刻停手，不会转头去咬第二朵。
- 死后原地长花：黄猫必掉；其他猫在死亡时若有花条，150~210 秒后长；猎手 15~45 秒。

### 物理与画面

- 矛 / 石头 / 珍珠等物件都有物理：矛头朝前顺着整体飞行，掷出去的矛先平飞一段再自然下落，飞行时带拖尾；只有运动中的矛会造成伤害，落地或插墙立刻停住不再抖（被捡起才恢复）。插在生物身上的矛随时能拔下来，只有变成杆的拔不出来。
- 生物体节的速度有上限（原版级冲量封顶），身位重叠时不会被解算器灌出「炮弹」速度。
- 屏幕整体带一层原版风格的像素滤镜，所有像素画都做了干净的像素化，没有半透明锯齿；贴地的物件与部件不会画到窗口地面线以下。
- **矛的绘制层级** —— 手上拿的矛、扎进生物身体里的矛都画在蛞蝓猫与生物之前（它们跟着身体走，压在上层会像贴在身上）；背上的矛画在猫身后；扎成杆的矛是场景物件，仍画在上层。
- **矛的碰撞、附着与绘制共用同一套几何** —— 命中判定求的是「矛轴线第一次穿进生物身体圆」的真实交点（不是这一帧的终点），刺中时矛尖正好落在交点上；插在生物身上的矛记的是「扎在哪一节身体 + 局部坐标 + 相对角度」，身体弯曲 / 扭身 / 甩尾时矛跟着那一节一起转，而不是只跟着平移；掷出的矛过了平飞段开始自然下坠时，矛身朝向跟随速度（矛头在前），不再出手后把角度锁死。
- 生物的贴图都按原版「多个角度 / 多档变体」取片，不会停在某一帧：蜥蜴头 5 片按头深度切 4 行、腿按长度与前后取 01~54 档；蝉乌贼 9 行按 z 轴角度整体切；蛞蝓猫头（HeadA/B/C 各 18 行）、脸（FaceA~D 各 9 行）、腿（走 / 爬 / 空中 / 横杆 / 竖杆 / 墙各一族）、手（PlayerArm0~12 按肩手距离）逐帧取档；面条蝇的翅与獠牙按 z 轴侧别取片；拾荒者手掌 A/B 按是否够到落点取片。`tools/sprite_variants.py` 可一键复核（整套跑下来零缺件）。移植全过程见 [docs/DECOMPILE_PROCESS.md](docs/DECOMPILE_PROCESS.md)：图层看 `InitiateSprites` 下标、位置与角度照 `DrawSprites`、锚点按 `ay = 1 - anchorY` 换算、尺寸取图集 `sourceSize`，骨骼与 AI 逐行照抄并标行号。
