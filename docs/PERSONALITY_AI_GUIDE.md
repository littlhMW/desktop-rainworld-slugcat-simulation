# 蛞蝓猫性格与 AI 行为说明

这份说明对应当前桌宠实现。性格不是一个固定标签，而是每只猫的一组连续数值；它们影响“想做什么”、路线排序和社交反应，不能绕过受伤、死亡、威胁、体力或角色能力的硬限制。

## 六个性格因子

所有因子都在 `0..1`：

| 因子 | 高值倾向 | 低值倾向 |
| --- | --- | --- |
| 同情心 `compassion` | 更愿意靠近、照料、帮助同伴和温和生物；更少主动攻击 | 更少为了救援停留，更容易把注意力放回自己 |
| 勇气 `courage` | 更能承受威胁，愿意拾取物品、接近危险并尝试攻击 | 更容易退避，危险时优先保持距离 |
| 活力 `vitality` | 更常玩耍、移动、拾取和进行鼠标互动 | 更常休息、打盹和停留在玩家附近 |
| 焦虑性 `anxiety` | 更快注意危险和不安，倾向靠近安全位置或玩家，也更容易尝试挣脱 | 更少因小威胁改变计划 |
| 攻击性 `aggression` | 更偏好矛、手雷等武器，受伤或被挑衅时更可能挑战 | 更偏向躲避、观察或换目标 |
| 强势性 `dominance` | 更愿意争抢、持有物品、保持自己的空间和路线 | 更容易让路、保持近距离并放弃争抢 |

项目保留了旧字段 `activity`、`bravery`、`kindness`、`temper` 等兼容定义。角色原型仍可使用这些字段；创建个体时会把原型加上稳定的随机偏移，随后得到六个可直接读取的 canonical 因子。怪猫还会定时重新抽取性格，因此表现会发生变化。

## AI 决策流程

每个模拟 tick，AI 按以下顺序工作：

1. **硬状态优先**：死亡、被抓、眩晕、游泳、暴雨、严重威胁、体力耗尽等状态先处理。性格不能让猫在这些状态下执行冲突动作。
2. **欲望候选**：空闲时在爬杆、横杆、吊顶、追鼠标、玩物品、社交、趋暖、觅食和待机之间选择。候选有累积值（freshness）、体力门槛、环境门槛和冷却；性格改变权重和体力门槛，而不是每帧直接强行切换动作。
3. **路线排序**：Planner 为走路、跳跃、爬杆、舌头、吊顶等路线估算时间、体力、风险、噪音、落点精度和恢复时间。勇敢、能承受风险的猫更愿意采用跳跃或舌头路线；谨慎的猫更偏好走路、低风险杆路。路线执行中会检查进度，失败后换方案或进入冷却。
4. **动作执行与重规划**：真正执行时仍使用统一的表面、杆和墙导航。目标不可达、被阻挡或环境改变时，控制器会结束并重新规划，不把一次失败变成无限重试。
5. **社交反应**：看到同伴受伤、被抢、被威胁或被救援时，AI 在忽略、跟随、观察、指向、斥责、挑战、询问和交换之间按性格与关系加权选择。

## 性格如何落到常见行为

- **玩耍**：活力提高爬杆、横杆、吊顶、鼠标和物品玩耍的权重；低活力猫更容易进入休息或睡眠。角色自己的 `toy_pref` 还会对某类玩耍做额外加权。
- **危险**：勇气提高接近威胁和战斗路线的接受度；焦虑提高危险关注、靠近安全点和挣脱倾向。真正的投掷物规避由投掷意图和弹道决定，不会因为性格高就预先躲避所有远处投掷物。
- **武器**：攻击性提高拿矛、手雷和攻击行为的倾向；角色能力仍是硬闸，例如圣徒的 `no_spear` 会禁止拿矛。
- **救援与照料**：同情心提高帮助、跟随和照料同伴的权重；威胁、距离、体力和当前动作会抑制不安全的救援。
- **拥挤与挡路**：强势性高的猫更可能坚持自己的路线或争抢物品；强势性低、耐心高的猫更容易让路。连续被同伴挡住时，统一阻挡系统会先尝试跳过，失败后再推开或结束该路线。
- **鼠标互动**：活力、玩耍倾向和角色特殊能力共同决定追逐、抓取、舔、攻击等动作；鼠标互动有独立概率和冷却，不会每帧触发。

## 如何读状态面板

状态面板显示当前实际动作和最终目标。例如“爬杆 → 横杆上的果子”表示猫当前正在爬杆，但路线最终目标是果子；“规避 → 庇护所”表示当前在躲避危险，最终目标是进入庇护所。性格因子只影响选择和排序，面板不会把性格本身当作动作。

## 调试与扩展建议

修改性格时优先使用：

```python
personality.with_traits(compassion=0.8, courage=0.3, vitality=0.7,
                        anxiety=0.6, aggression=0.2, dominance=0.4)
```

不要在单个动作里直接写“某性格一定做某事”。更稳定的做法是调整候选权重、路线代价或社交反应权重，并保留能力、环境和冷却门。这样同一套 AI 可以被不同蛞蝓猫和蜥蜴复用。

实现位置：`cats/personality.py`、`behavior/desire.py`、`planning/route.py`、`planning/planner.py`、`behavior/social_response.py`、`behavior/fsm.py`。
