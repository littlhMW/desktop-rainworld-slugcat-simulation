# 蛞蝓猫特殊游玩能力清单

这份清单专门记录当前桌宠版本已经接入的“鼠标互动型特殊游玩”：角色会主动追逐、抓取、舔或攻击鼠标，并使用独特动作。普通移动、寻路、进食、社交、救援和战斗属于共享 AI，不重复列在每个角色下。

| 角色 | 当前特殊游玩/能力 |
| --- | --- |
| Monk（僧侣） | 无独占鼠标动作；可使用共享追鼠标和指向社交。 |
| Survivor（求生者） | 无独占鼠标动作；`waa / SU_7` 是全局威慑音频，不属于鼠标互动。 |
| Hunter（猎手） | **PinCursorSpear**：鼠标在附近停留时，偶尔抽出矛投向并钉住鼠标；甩动鼠标可脱钉。此项是本项目桌宠扩展设计。 |
| Gourmand（饕餮） | 无独占鼠标动作；Slam 只用于威胁战斗，鼠标仍走共享追逐。 |
| Artificer（工匠） | **PyroMaul**：鼠标经过或停留后，走近抓住并啃咬；距离较远时概率爆跳扑抓。 |
| Rivulet（雨） | **RivSnatch**：鼠标在中下区域停留后，走位并后空翻掠过抓住，携带鼠标约 10 秒。 |
| Spearmaster（矛大师） | 无独占鼠标动作；尾针生成和特殊食性不以鼠标为目标。 |
| Saint（圣徒） | **CursorLick**：走到鼠标下方吐舌，附着后吊挂并跟随鼠标；另有超度时追踪鼠标。 |
| Watcher（守望者） | **WatcherFloat**：偶尔在鼠标 x 位置高跳，最高点闭眼并渐隐，带延迟缓慢跟随鼠标约 4 秒；身体周围是贴身蓝紫扭曲火焰。 |
| Inv（怪猫） | 无独占鼠标动作；独占行为是近身撕咬蜥蜴。 |
| Slugpup（蛞蝓猫幼崽） | 无独占鼠标动作；使用幼崽骨架和求生者式基础行为。 |

共享的 **ChaseCursor** 会让所有允许注意鼠标的猫寻路靠近，并在抵达后指向或斥责；它不计入角色独占特殊游玩。

## Watcher 浮游状态说明

- 触发前提：守望者处于站立空闲、脚接触地面、没有威胁、鼠标注意权限开启且不在冷却中。
- 起跳阶段仍使用身体物理；达到最低上升高度并接近最高点后切换为悬浮。
- 悬浮阶段不瞬移，不锁定鼠标位置；只对水平目标做低增益滞后跟随，并保留鼠标拖动与碰撞接口。
- 受到死亡、抓取、眩晕或其他独占状态打断时会清理透明度、悬浮标志和特效。

来源与实现边界：能力名称和行为目标参考 Rain World 角色资料与现有反编译笔记；本项目只实现桌宠环境所需的轻量化表现，不携带原版游戏资源或工坊文件。
