# 蛞蝓猫特殊游玩能力清单

这份清单记录当前桌宠版本已经接入的角色专属行为，以及它们在代码中的入口。普通移动、寻路、进食、社交、救援和战斗属于共享 AI，不重复列在每个角色下。

| 角色 | 当前特殊游玩/能力 |
| --- | --- |
| Monk（僧侣） | 低攻击倾向、亲近同伴和鼠标；共享匍匐、休息、社交行为。 |
| Survivor（求生者） | 无独占动作；可使用 `waa / SU_7` 威慑彩蛋（由全局设置和威胁条件控制）。 |
| Hunter（猎手） | 后备矛、背矛和双矛携带；更快的移动与投掷节奏。 |
| Gourmand（饕餮） | Slam 重量坠落/震击动作；落地冲击和较重的物理表现。 |
| Artificer（工匠） | 爆跳、爆炸和 PyroMaul；爆炸会影响附近实体与地形。 |
| Rivulet（雨） | 后空翻抓横杆、夺取鼠标，以及水下游泳和鳃部表现。 |
| Spearmaster（矛大师） | 尾部生成白针；特殊食性和针矛互动。 |
| Saint（圣徒） | 舌头抓取、舌爬墙/吊顶、超度，以及舔鼠标；禁用持矛。 |
| Watcher（守望者） | 发光、伪装；安静且落地时偶尔触发“追光浮游”：高跳到鼠标附近，在最高处闭眼、渐隐并以延迟缓慢跟随鼠标约 4 秒，伴随蓝紫扭曲火焰环。 |
| Inv（怪猫） | 活体撕咬和性格重抽；使用共享移动、战斗和社交系统。 |
| Slugpup（蛞蝓猫幼崽） | 幼崽骨架/缩放/食条；继承求生者式的基础行为，不额外注册独占动作。 |

## Watcher 浮游状态说明

- 触发前提：守望者处于站立空闲、脚接触地面、没有威胁、鼠标注意权限开启且不在冷却中。
- 起跳阶段仍使用身体物理；达到最低上升高度并接近最高点后切换为悬浮。
- 悬浮阶段不瞬移，不锁定鼠标位置；只对水平目标做低增益滞后跟随，并保留鼠标拖动与碰撞接口。
- 受到死亡、抓取、眩晕或其他独占状态打断时会清理透明度、悬浮标志和特效。

来源与实现边界：能力名称和行为目标参考 Rain World 角色资料与现有反编译笔记；本项目只实现桌宠环境所需的轻量化表现，不携带原版游戏资源或工坊文件。
